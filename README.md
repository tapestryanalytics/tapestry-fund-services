# Tapestry Website

Static, multi-page website for GitHub Pages.

## Pages
- Home
- Services
- Software
- Tapestry Fund Analytics product page
- Insights
- About
- Contact

## Publish on GitHub Pages
1. Upload every file and folder to the repository root.
2. In GitHub, open Settings > Pages.
3. Select Deploy from a branch, `main`, `/root`.
4. Save.

## Contact form
The contact page currently uses the existing Formspree endpoint supplied for Tapestry. Update it in `contact.html` if needed.
